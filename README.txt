SES_Core - Neon Overdrive Edition

【起動方法】
1. ZIPを展開します。
2. SES_Core/index.html を Chrome または Microsoft Edge で開きます。
3. デモログイン情報を入力します。
   ユーザーID: admin
   パスワード: SESCore2026!

【デザイン更新】
ネオン感を高めるため、css/neon-overdrive.css を追加しました。
背景に複数色のグラデーションとサイバーグリッドを追加し、カード、メニュー、見出し、入力欄、ボタンにシアン・ブルー・パープル・ピンクの発光表現を適用しています。
通常テーマでは過剰な発光を抑え、読みやすさを維持します。

【ファイル構成】
index.html
css/style.css
css/extensions.css
css/neon-overdrive.css
js/app.js
js/extensions.js
js/tailwind-config.js

【注意】
本アプリは個人PC向けの試作版です。ログインおよび権限制御はフロントエンド上のデモ実装であり、本番環境向けのセキュリティを保証しません。
一部のライブラリ・フォントはCDNから読み込むため、該当機能の利用にはインターネット接続が必要です。
既存の保存データを保護するため、アップデート前にJSONバックアップを取得してください。


【今回の追加機能】
・トップバーのログアウトボタン
・売上管理をメンバー別（行）×月別（列）の年間マトリクスに変更
・スポット業務（単発売上）の登録・一覧・削除
・経費登録のメニュー、登録・一覧・削除
・金額入力単位は万円（例：15 = 150,000円）
・月別売上は初期値として稼働中メンバーの月額単価を表示し、セル編集で上書き可能
