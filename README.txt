SES_Core Ver.1.00 / 現行ブラウザ版 R10
移行元：v3.2.138

■起動
1. ZIPを展開して SES_Core/index.html をChromeまたはEdgeで開きます。
2. 現行アカウントでログインします。Tailwind CSS・アイコン・グラフ・フォントは既存のCDNを利用します。
3. データはブラウザ内に保存され、通常の起動にはJava・PostgreSQLは不要です。

■R10の変更
・最重要タスクの手動登録・自動登録・絞り込み。
・待機中および本日以降の契約終了日を社員・案件・終了日単位で自動登録。
・完了済みはダッシュボード非表示。自動登録タスクは削除不可。
・ダッシュボード先頭に折り畳み可能な一覧を追加。

■R09の変更（メンバー別の期間合計）
・「売上・粗利管理」→「メンバー別」で、各メンバーの最後の案件行の右端に、
  選択期間の売上合計と粗利合計を表示します。1案件のメンバーにも表示します。
・複数案件の場合は案件ごとの期間金額も表示します。一括登録や既存の集計・入力方法は従来どおりです。

■R08の変更（参画案件の一括登録）
・「メンバー管理」→ 社員の「編集」→「参画案件の一括登録」を開き、
  「＋ 参画案件を追加」で必要な行を追加します。案件、開始日、契約終了日、月額単価（円）、
  稼働割合（%）を入力し、社員編集の「保存」でまとめて登録します。案件は「案件管理」で事前登録します。
・異なる案件の期間は重複して登録できます。同じ案件への再参画は期間を分けて登録できます。
  契約終了日を空欄にした場合、案件に契約終了日があればその日を使用します。
・既存の参画案件と今後の予定は一括登録欄の上部に表示します。R07の案件切替は従来の切替欄から行えます。
・「売上・粗利管理」→「メンバー別」では、同月の参画案件を案件別に表示します。
  一括登録した案件の予定売上の初期値は月額単価×稼働割合です。日割りは必要に応じて手入力します。
  登録済み月次金額を保持し、配賦先が未確定の金額は「案件未配賦」に表示します。
  掛け持ち月の原価・交通費は手動で配賦します。案件行の粗利はその行の入力額に基づきます。
  実績は案件別に入力するか、予定をコピーして登録できます。

■既存データの引継ぎ
異なるZIP展開先・URL・ブラウザプロファイルでは保存領域が変わることがあります。
更新前に現行版で設定のJSONバックアップを取得し、必要に応じて新しい環境で取り込んでください。
アカウント・プロフィール・チャット・テーマは業務JSONとは別の保存領域です。既存ブラウザ・同じURLでの上書き更新が引継ぎに適します。
元のフォルダやバックアップは確認が終わるまで保持します。

■スポット業務の編集と経費
・スポット業務一覧の「編集」から登録内容を変更できます。紐づく通常経費にも日付、担当、費目、金額の変更が反映されます。
・スポット業務と通常経費の費目に「交際費」を追加しました。

■メンバー別の売上・粗利
・対象メンバーの直下にスポット業務売上と物販売上を表示します。経費はメンバーの月別欄で交通費と粗利の間に表示します。
・月別と期間のメンバー売上・粗利に反映し、表の下部にも従来の累計を表示します。
・SES_Core_Backup_2026-11-26(1).json を初回起動データとして取り込み済みです。既に同じ場所で保存しているブラウザでは、その保存データを優先します。

■参画情報・スポット業務の更新
・社員編集の「現在の参画案件」自由入力欄を削除しました。社員詳細と「案件参画情報」には、案件とメンバーの紐づけを表示します。
・案件詳細の「○人参画中」を開くと参画者を確認できます。登録されている参画期間に基づいて表示します。
・スポット業務に粗利（経費控除前）と経費を追加しました。経費は通常の経費登録にも表示されます。
・売上・粗利管理では、スポット入力時の粗利から登録経費を一度だけ控除します。過去分に粗利登録がない場合は従来どおり売上と同額で扱います。
・スポット業務を削除すると紐づいた経費も削除されます。経費一覧で経費だけを削除すると、スポット業務の経費表示にも反映されます。

■前回の変更
・グレード管理：対象期を選択。既存のグレードと割当は第15期に引き継ぎます。
  後続期は前の登録期からマスターを明示的にコピーし、その期の割当を登録します。
・グレード原価：対象期の登録済み予定・実績原価に反映します。締め済み実績も含みます。
  他期・他社員・未登録原価には波及しません。原価は現行と同じ地方想定原価を参照します。
・メンバー単価：編集保存で変更前後を記録し、詳細画面に表示します。
  「予定売上へ反映」で、開始月から期末までの予定売上を手動更新します。
・マッチングに共有案件と参画案件を表示します。従来どおり見送り・募集終了を除外します。
・募集案件と見送りのKPIは、この版で記録された状態変更を対象に集計します。
  新規登録は状態変更に含めず、旧データからの履歴は推定で作成しません。

■営業・月次管理（業務支援メニュー）
・契約更新ボードでは参画案件ごとの対応状況、担当、期限を保存できます。単価登録は既存の単価・交渉条件画面から行います。
・案件別収支は対象月の実績です。案件IDがない明細は、対象月に参画先が1件のメンバーに限り配賦します。それ以外は案件未配賦として集計します。
・月次締めでは予定と実績の売上差を確認し、経費確認後に管理者が集計を確定します。訂正時は理由を入力して再開します。
・定例会資料は対象月を指定してCSV出力できます。前回の議事録の未完了事項も含みます。

■運用範囲
現行のブラウザ保存・アカウント方式を継承した版です。PostgreSQL適用・データ移行は実施していません。

・全画面共通CSSで余白、見出し、選択値の左寄せを調整。

R16 定例会・1on1連携
定例会新規登録時に開催日以前の最新1on1（社員別）と顧客フィードバック（社員・顧客・案件別）を取得します。最新情報を追加取得ボタンで追加できます。参照内容は議事録に保存し、元記録は変更しません。参加者はリーダー以上の複数選択（Ctrlキー）です。1on1は担当者を選ぶと所属・管轄部署の社員に絞り込みます。

R17: 2026年11月の架空サンプル（1on1 18件、顧客フィードバック19件、定例会1件）。待機者は評価なし。既存ローカル保存データには自動上書きしません。

R23: NEON専用の同系色グラデーション、内外発光、操作別配色、プルダウン・タブ・サイドメニュー統一。STANDARDと業務データは変更なし。ネイティブ選択肢の描画はOS依存。
