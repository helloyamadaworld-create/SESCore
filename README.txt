SES_Core Ver.1.00 / 現行ブラウザ版
移行元：v3.2.138

■起動
1. ZIPを展開して SES_Core/index.html をChromeまたはEdgeで開きます。
2. 現行アカウントでログインします。Tailwind CSS・アイコン・グラフ・フォントは既存のCDNを利用します。
3. データはブラウザ内に保存され、通常の起動にはJava・PostgreSQLは不要です。

■既存データの引継ぎ
異なるZIP展開先・URL・ブラウザプロファイルでは保存領域が変わることがあります。
更新前に現行版で設定のJSONバックアップを取得し、必要に応じて新しい環境で取り込んでください。
アカウント・プロフィール・チャット・テーマは業務JSONとは別の保存領域です。既存ブラウザ・同じURLでの上書き更新が引継ぎに適します。
元のフォルダやバックアップは確認が終わるまで保持します。

■今回の変更
・グレード管理：対象期を選択。既存のグレードと割当は第15期に引き継ぎます。
  後続期は前の登録期からマスターを明示的にコピーし、その期の割当を登録します。
・グレード原価：対象期の登録済み予定・実績原価に反映します。締め済み実績も含みます。
  他期・他社員・未登録原価には波及しません。原価は現行と同じ地方想定原価を参照します。
・メンバー単価：編集保存で変更前後を記録し、詳細画面に表示します。
  「予定売上へ反映」で、開始月から期末までの予定売上を手動更新します。
・マッチングに共有案件と参画案件を表示します。従来どおり見送り・募集終了を除外します。
・募集案件と見送りのKPIは、この版で記録された状態変更を対象に集計します。
  新規登録は状態変更に含めず、旧データからの履歴は推定で作成しません。

■運用範囲
現行のブラウザ保存・アカウント方式を継承した版です。PostgreSQL適用・データ移行は実施していません。
