SES_Core - Neon Overdrive Edition

【起動方法】
1. ZIPを展開します。
2. SES_Core/index.html を Chrome または Microsoft Edge で開きます。
3. デモログイン情報を入力します。
   ユーザーID: admin
   パスワード: SESCore2026!

【デザイン更新】
ネオン感を高めるため、css/neon-overdrive.css を追加しました。
背景に複数色のグラデーションとサイバーグリッドを追加し、カード、メニュー、見出し、入力欄、ボタンにシアン・ブルー・パープル・ピンクの発光表現を適用しています。
通常テーマでは過剰な発光を抑え、読みやすさを維持します。

【ファイル構成】
index.html
css/style.css
css/extensions.css
css/neon-overdrive.css
js/app.js
js/extensions.js
js/tailwind-config.js

【注意】
本アプリは個人PC向けの試作版です。ログインおよび権限制御はフロントエンド上のデモ実装であり、本番環境向けのセキュリティを保証しません。
一部のライブラリ・フォントはCDNから読み込むため、該当機能の利用にはインターネット接続が必要です。
既存の保存データを保護するため、アップデート前にJSONバックアップを取得してください。


【今回の追加機能】
・トップバーのログアウトボタン
・売上管理をメンバー別（行）×月別（列）の年間マトリクスに変更
・スポット業務（単発売上）の登録・一覧・削除
・経費登録のメニュー、登録・一覧・削除
・金額入力単位は万円（例：15 = 150,000円）
・月別売上は初期値として稼働中メンバーの月額単価を表示し、セル編集で上書き可能


今回の更新:
- data/SES_Core_Data.json に提供されたJSONデータを同梱。初回起動時の初期データとして使用します。
- 人材マッチングは「待機中」「提案中」のメンバーのみを表示します。ステータス別の絞り込みも可能です。
- 既存のブラウザ保存データがある場合はそのデータを優先し、メンバー単価・ステータスを自動で上書きしません。

【今回の拡張：案件管理とデータ連動】
・案件・プロジェクト管理を「共有案件」「参画案件」の切り替え式に変更しました。
・メンバーの assignedProjectId / currentProject、案件の assignedMemberIds を参照して、未分類の既存案件を自動分類します。自動分類後は projectType として保存され、案件編集画面から変更できます。
・案件ステータスに「見送り」を追加しました。案件一覧のステータス絞り込み、分析レポート、ダッシュボードにも反映します。
・取引先一覧の案件数は、登録済み案件データから再集計します（見送り・募集終了は除外）。
・人材マッチングでは見送り／募集終了の案件と参画案件を候補から除外し、共有案件を対象にします。
・アップデート前にJSONバックアップを取得してください。


【今回の更新：ステータス2系統・全画面背景】
- メンバーごとに「現在のステータス」と「来月以降のステータス」を管理します。
- ダッシュボード・通常のメンバー一覧・売上等は現在のステータスを参照します。
- 人材マッチングは来月以降のステータスを参照し、「待機中」「提案中」の要員を抽出します。
- ログイン画面とオープニング画面をビューポート全体に固定し、下部背景が見切れる問題を修正しました。


今回の更新:
- 取引先企業一覧に参照元シート「取引先マスタ」を明記
- 案件・プロジェクト管理に参照元シート「案件情報」を明記
- メンバー表示順を指定順に変更し、一覧に連番を表示
- 指定外の既存メンバー（佐々木 翔平）はデータを削除せず末尾に保持


【v3.2.0 追加・変更】
・案件一覧に参画人数と参画メンバー詳細ダイアログを追加。
・案件詳細からメンバーの追加、単価変更、参画解除が可能。
・案件想定単価／メンバー別参画単価は円単位で登録し、画面は万円単位で表示。
・案件ステータスに「参画中」を追加。
・取引先名、取引先名＋案件名を基準に重複データを統合。
・別添の「SES_Core_取引先案件_重複整理済み_v3.2.0.json」は取引先・案件の重複整理済みデータ。
